Этот документ фиксирует, что и откуда изучалось при создании hhauto.
Дата ревизии: 2026-09-24. Источник требований: [PLAN.md §11](PLAN.md).

## Текущий статус: код доноров не копировался

**Весь код hhauto написан с нуля по мотивам изученного поведения.** У доноров
бралась идея, алгоритмическое поведение или знание предметной области — не
байты. Файлов, скопированных целиком или частично, нет; заголовков-комментариев
происхождения в коде нет, потому что нет скопированных фрагментов. Поэтому
правило SHA-пиннинга ниже сейчас не имеет применённых записей — оно включено
для любых будущих заимствований.

## Provenance-политика

1. Каждый заимствованный фрагмент кода **больше 10 строк** обязан нести
   заголовок-комментарий с источником и запись в этом файле: репозиторий,
   SHA коммита-источника, лицензия, что изменено.
2. Файлы, скопированные целиком, фиксируются в [NOTICE/THIRD-PARTY.md](../NOTICE/THIRD-PARTY.md).
3. **SHA-пиннинг**: заимствования фиксируются по конкретному SHA коммита,
   не по ветке `main` и не по «текущему состоянию». Ветка или релиз донора
   могут исчезнуть; SHA в записи позволяет восстановить точный источник.
4. Лицензионный фильтр: код берётся только из репозиториев с MIT /
   Apache-2.0 / Unlicense / BSD. Non-commercial-лицензии (например,
   `hh-applicant-tool`) — только как изучаемое поведение, никогда как код.
   AGPL — не используется вовсе.
5. Новые заимствования добавляются в таблицы выше в том же PR, что и код.
